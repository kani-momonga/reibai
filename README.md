## テキスト化について

- テキストはUTF-8で保存し、各ページの先頭にページ番号を付けています。
- PDFから文字を抽出できなかったページは画像OCRでテキスト化し、ページ見出しに「OCR」と表示しています。全268ページ中187ページがOCR対象です。
- OCRには誤認識が残る場合があります。引用や内容確認には原本PDFを参照してください。
