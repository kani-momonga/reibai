## 利用上の注意

- サマリは各書面に書かれた主張・記載内容の整理です。判決の認定・判断と当事者の主張は、各ファイル内で区別しています。
- OCRを含む資料には誤認識があり得ます。正確な引用、数値、法令・判例の確認には原本PDFを参照してください。
- 法的助言ではなく、資料の読解補助を目的としています。
